# Foam Cleaning — точная копия

Копия HTML сайта https://helpful-phoenix-3e63a1.netlify.app/, полученная 14 ноября 2026 года по поручению владельца материалов. `index.html` сохранён побайтово: внешний вид, тексты, калькулятор и Метрика не изменены.

## Проверка

```sh
python3 serve.py
```

Откройте http://127.0.0.1:8000. Или откройте `index.html` в браузере. Для статического хостинга публикуйте только `index.html`.

## Яндекс.Метрика

Счётчик **114250008** установлен ровно один раз. Включены webvisor, clickmap, accurateTrackBounce, trackLinks и ecommerce dataLayer. В калькуляторе есть цель `calc_submit`. Код не содержит токенов доступа к кабинету Метрики. После смены адреса сайта обновите адрес в настройках счётчика; номер остаётся прежним.

## Унаследованные ограничения

- Метрика запускается сразу; баннер OK только скрывается и не управляет согласием.
- Калькулятор показывает модальное окно успеха, но не отправляет заявку на сервер. Цель calc_submit означает действие в интерфейсе, а не подтверждённую доставку заявки.
- Формы PDF и бронирования не подключены к обработчику.
- Контакты, ИНН/ОГРНИП, ссылки на политики, отзывы и бизнес-показатели перенесены из исходника без подтверждения. Ссылки на документы ведут на #.
- Шрифты загружаются с jsDelivr. Внешняя доступность шрифтов и Метрики зависит от сети и блокировщиков.
- Это точная копия для проверки, не подтверждение юридической или production-готовности. Backend, база данных и админка не добавлены.
